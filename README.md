# Customer Behavior Analysis

## Project Overview
This project focuses on analyzing customer transaction and behavior data using Python and Jupyter Notebook. The objective of the analysis is to identify customer purchase patterns, spending behavior, and customer segments to help businesses improve customer engagement and decision-making.

The project was completed as part of an internship task for Alfido Tech.

---

## Dataset
Dataset used from Kaggle:

https://www.kaggle.com/datasets/bhanupratapbiswas/customer-behavior-analysis

---

## Objectives
- Perform data cleaning and preprocessing
- Analyze customer behavior and transactions
- Generate summary statistics
- Create meaningful visualizations
- Identify customer spending patterns
- Build customer segments using RFM analysis
- Provide actionable business insights

---

## Tools & Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Tasks Performed

### 1. Data Cleaning
- Removed missing values
- Removed duplicate records
- Converted date columns into datetime format

### 2. Summary Statistics
- Mean
- Median
- Mode
- Missing value analysis
- Data type inspection

### 3. Feature Engineering
- Created Total Spending column
- Generated RFM metrics:
  - Recency
  - Frequency
  - Monetary

### 4. Data Visualization
The following visualizations were created:
- Bar Chart
- Histogram
- Pie Chart
- Customer Segmentation Graphs

### 5. Customer Segmentation
Customers were segmented using RFM analysis and clustering techniques to identify:
- High-value customers
- Frequent buyers
- Potential churn customers

---

## Key Insights
1. Certain product categories generated the highest number of purchases.
2. A small group of customers contributed significantly to overall revenue.
3. Most customers preferred a specific payment method for transactions.

---

## Recommendations for Alfido Tech
1. Focus marketing campaigns on high-performing product categories.
2. Provide loyalty rewards for high-spending customers.
3. Use personalized offers to improve customer retention.
4. Target inactive customers with re-engagement campaigns.
5. Optimize payment methods for better customer convenience.
